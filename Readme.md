# Assignment 4 - Python File Handling

This assignment covers reading, writing and appending data to files using Python.

## Tasks

- Task 1: Write sales records to a file.
- Task 2: Read a file using `read()`, `readline()` and `readlines()`.
- Task 3: Append new sales records.
- Task 4: Calculate a sales summary from a file.
- Task 5: Save and read product information.
- Task 6: Check whether a file exists before reading it.
- Task 7: Calculate discounted prices and save a report.

## How to Run

Make sure Python 3 is installed. Open the terminal in the assignment folder and run each file separately.

```bash
python Task_1.py
python Task_2.py
python Task_3.py
python Task_4.py
python Task_5.py
python Task_6.py
python Task_7.py
```

Tasks 2–4 use `sales_data.txt`, which is created by Task 1. Run Task 1 first.

Task 5 creates `products.txt`, and Task 7 creates `discount_report.txt`.

## What I Practised

I practised file modes, reading and writing text files, appending records, converting text into numbers, and generating simple reports.
